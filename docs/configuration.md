# Configuration

All configuration comes from environment variables / the repository-root `.env` file
(`apps/api/eyohe/core/config.py`). Secrets are never returned by the API; the Settings page shows
them masked. Non-secret runtime settings (model, bounds, classification) can also be overridden
from the UI (`PATCH /api/v1/settings`) and are stored in `system_settings`.

| Variable | Default | Purpose |
|---|---|---|
| `EYOHE_ENV` | `development` | `development` / `production` / `test` |
| `SECRET_KEY` | — | generated by `make setup`; required in production |
| `DATABASE_URL` | SQLite | `postgresql+asyncpg://user:pass@host:5432/eyohe` recommended |
| `REDIS_URL` | `redis://127.0.0.1:6379/0` | optional |
| `JOB_BACKEND` | `embedded` | `embedded` runs jobs inside the API; `arq` uses the worker container |
| `GRAPH_BACKEND` | `postgresql` | `neo4j` enables the optional Neo4j adapter |
| `OLLAMA_URL` / `OLLAMA_MODEL` | `http://127.0.0.1:11434` / `qwen3:8b` | any Ollama model with tool support (Qwen, Llama, DeepSeek, Gemma) |
| `OLLAMA_TIMEOUT_SECONDS` / `OLLAMA_NUM_CTX` | `600` / `8192` | lower the context on weak CPUs |
| `SEARCH_PROVIDERS` | `searxng` | comma-separated priority list: `searxng,brave,serper,tavily` |
| `SEARXNG_URL`, `BRAVE_API_KEY`, `SERPER_API_KEY`, `TAVILY_API_KEY` | — | provider configuration; missing keys produce a configuration error, never fake results |
| `GITHUB_TOKEN` | — | raises GitHub rate limits and enables public code search |
| `REDDIT_USER_AGENT` | descriptive UA | required by Reddit's public JSON endpoints |
| `MAX_AGENT_ITERATIONS`, `MAX_RESEARCH_DEPTH`, `MAX_QUERIES`, `MAX_PAGES`, `MAX_RUNTIME_SECONDS`, `MAX_RESULTS_PER_SOURCE` | 50 / 2 / 40 / 60 / 1800 / 20 | investigation bounds (analysts may raise them up to 4× per investigation) |
| `REQUEST_TIMEOUT`, `MAX_FETCH_BYTES` | 20 s / 5 MB | outbound HTTP limits |
| `DATA_DIR`, `EVIDENCE_RETENTION_DAYS`, `SNAPSHOT_MAX_TEXT_CHARS` | `./data`, 0 (keep), 200k | evidence vault |
| `SESSION_TTL_HOURS`, `COOKIE_SECURE` | 24, false | set `COOKIE_SECURE=true` behind HTTPS |
| `ALLOW_PRIVATE_NETWORK_FETCH` | false | **dangerous**; disables SSRF address checks for local testing only |
| `RATE_LIMIT_PER_MINUTE`, `AUTH_RATE_LIMIT_PER_MINUTE` | 240, 10 | per-IP limits |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ALERT_WEBHOOK_URL`, `SMTP_*` | — | alert delivery channels |
| `REPORT_CLASSIFICATION` | `RESEARCH` | `INTERNAL` / `RESEARCH` / `CONFIDENTIAL` label on reports |
| `CHROMIUM_PATH` | `/usr/bin/chromium` | PDF fallback engine |

## Search providers

- **SearXNG** (recommended): self-hosted meta-search. The bundled settings enable the JSON API and
  disable the bot limiter for local use. Do not expose it publicly.
- **Brave / Serper / Tavily**: keyed APIs. Respect their terms; Eyohe caches results (6 h) and
  deduplicates by canonical URL to minimise requests.

## Models

Any Ollama chat model works for the analyst; tool calling (research loop) needs a tool-capable
model (`qwen3`, `llama3.1`, `mistral-nemo`, …). Health shows whether the configured model is pulled.
